## `vestige prove`

The failure memory for each prove run is one `vestige ingest "failure: <name>"`. That memory has no git edges. `prove` therefore reports that the walk reached none of the commits in the range, and stock `git bisect run` decides. Ingest records are not leads: `record_content` starts `commit <sha> <subject>`, while `commit_named` accepts only text that starts `Commit <7-40 lowercase hex>:` or the same prefix followed by a space or a newline (`crates/vestige-mcp/src/walk_verify/run.rs`).

Checkout is not mutated. The test runs in a temporary worktree. Exit 0 is good, 125 is cannot-test, anything else at most 127 is bad. `vestige prove --check` re-verifies the report offline.

## What ingest reads from commit messages

The parsers are `crates/vestige-core/src/advanced/git_records.rs`. The log format is `%x1e%H%x1f%aI%x1f%P%x1f%s%x1f%b%x1d` (`GIT_LOG_PRETTY`): the body is a field of its own, and the subject is not scanned by these three functions. Issue numbers, free text, and subjects are not links.

A full SHA is 40 hex digits (`is_full_sha`). The first matching revert line wins. The first matching cherry-pick line wins.

### Revert

Exact line, after trim and CR strip: `This reverts commit <40 hex>.` The period is required. The prefix is case-sensitive. A short SHA, a missing period, and `this reverts commit` do not match. The SHA is stored lowercased.

```rust
pub fn revert_target(body: &str) -> Option<String> {
    for line in body.lines() {
        let line = line.trim_end_matches('\r').trim();
        let Some(rest) = line.strip_prefix("This reverts commit ") else {
            continue;
        };
        let Some(sha) = rest.strip_suffix('.') else {
            continue;
        };
        if is_full_sha(sha) {
            return Some(sha.to_ascii_lowercase());
        }
    }
    None
}
```

### Cherry-pick

Exact line: `(cherry picked from commit <40 hex>)`. The parentheses are required. A short SHA does not match. Anything else is not a cherry-pick.

```rust
pub fn cherry_picked_from(body: &str) -> Option<String> {
    for line in body.lines() {
        let line = line.trim_end_matches('\r').trim();
        let Some(rest) = line.strip_prefix("(cherry picked from commit ") else {
            continue;
        };
        let Some(sha) = rest.strip_suffix(')') else {
            continue;
        };
        if is_full_sha(sha) {
            return Some(sha.to_ascii_lowercase());
        }
    }
    None
}
```

### `Fixes:`

The line must start with `Fixes:` (capital F). The remainder of the line, after trim, must be a single whitespace-separated token of 12 to 40 hex digits and nothing else. `fixes:` is rejected. `Fixes: <sha> extra` is rejected. A SHA inside a sentence is rejected. This is not an issue number and not a subject.

A 12–39 hex token is a prefix. `resolve_fix_shas` in `crates/vestige-mcp/src/tools/repo_ingest.rs` replaces it with the one local commit that name resolves to. An ambiguous or missing prefix is dropped. Nothing is fetched.

```rust
pub fn fixes_targets(body: &str) -> Vec<String> {
    let mut out = Vec::new();
    for line in body.lines() {
        let line = line.trim_end_matches('\r').trim();
        let Some(rest) = line.strip_prefix("Fixes:") else {
            continue;
        };
        let rest = rest.trim();
        let mut tokens = rest.split_whitespace();
        let Some(sha) = tokens.next() else {
            continue;
        };
        if tokens.next().is_some() {
            continue;
        }
        if (12..=40).contains(&sha.len()) && sha.chars().all(|c| c.is_ascii_hexdigit()) {
            let sha = sha.to_ascii_lowercase();
            if !out.contains(&sha) {
                out.push(sha);
            }
        }
    }
    out
}
```
