# Benchmark setup contract

All model requests, paid provider calls, cloud GPU provisioning and publication
remain outside zero-inference preparation. Existing user credits are not a fresh
spending permit. Do not alter global native policies, keys, binaries or ledgers.

Preserve each upstream checkout and pin its commit, data, license and scorer.
Official benchmark tasks and locally added diagnostic fixtures have separate
identities. Never label synthetic outcomes as official model scores.

Keep gold labels and scoring annotations out of memory histories, retrieval tags,
causal edges and solver prompts. Retain unsupported, failed and missing-source
states explicitly. Source names without a verified identity remain unresolved.

Do not imply that a tool-call hook mediates arbitrary OS syscalls. Cryptographic
log integrity is separate from semantic truth or poisoning resistance. Enumerate
the actual current Operator IDs and native mechanism interfaces; never infer
availability from a pillar name, compiled metadata or a standalone math fixture.

Workers own only assigned paths, preserve others' changes and report exact
commands, source revisions, proof limits and blockers. Run relevant tests before
calling an adapter qualified. Use an independent verifier before launch claims.
