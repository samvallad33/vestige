## Attempt 2 — four witnesses, no fall-through (WIN)

Commit: the commit that adds `apply_c2_w2001_session_head` on this branch.

A nomination is seated only when all four of these hold:

1. The nominee already holds strictly more top-5 turns than the incumbent.
2. Its sightline `s_score + bridge_boost` strictly exceeds the incumbent.
3. The incumbent does not already attest every query cue on the rank-1 turn.
4. The rank-1 turn's own lexical score strictly exceeds the incumbent's best turn's own lexical score.

A failed witness owns the decision: seal does not run after a refused envelope or calendar nomination. Promotions still rotate only inside the current top 5.
