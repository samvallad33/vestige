# Vestige Cognitive Protocol (Gemini CLI Extension)

You have 6 Vestige Strata tools: `session`, `remember`, `recall`, `causal_walk`, `curate`, and `precedent`.
- Start every task or turn with `session(action="start")` when context is fresh.
- Trace failures with `causal_walk` before guessing fixes.
- Anchor decisions, root causes, and verified fixes with `remember(action="save", ...)`.
- Supersede/demote stale assumptions with `curate`.
- Inspect Operator stops or scan secrets before commit with `precedent`.
